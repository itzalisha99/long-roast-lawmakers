A make.fun entry for **The Long Roast: Lawmakers and the File They Cannot Convert**: one satirical sentence, 320 characters or fewer, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

## The roast

> The senator who wrote the AI safety bill still emails his staff a Word document called 'FINAL_final_v7_USE_THIS_ONE' and asks an intern to turn it into a PDF.

## How it works

`main.py` (Python stdlib only, deterministic) writes the roast to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–320 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
